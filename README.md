## Featured Projects

### 1. [ROS 2 SLAM & Navigation](https://github.com/shalinimarieno-byte/ROS2-SLAM-Navigation)
Simultaneous Localization and Mapping with autonomous trajectory planning and real-time occupancy map generation in ROS 2.

### 2. [Leader-Follower Robot](https://github.com/shalinimarieno-byte/Leader-Follower-Robot)
Multi-robot cooperative system where a follower unit dynamically tracks and mirrors the movement of a lead robot unit.

### 3. [Hand Gesture Control Robot](https://github.com/shalinimarieno-byte/Hand-Gesture-Control-Robot)
Intuitive robotic motion control system interpreting real-time hand gesture vectors into movement commands.

### 4. [Obstacle Avoidance Robot](https://github.com/shalinimarieno-byte/Obstacle-Avoidance-Robot)
Autonomous obstacle detection and dynamic path selection system utilizing sensor fusion and rapid reactive motor control.

### 5. [Line Follower Robot](https://github.com/shalinimarieno-byte/Line-Follower-Robot)
High-precision autonomous line tracking mobile robot using optical sensor arrays and feedback control algorithms.
